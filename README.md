# DevTracker

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## Overview

DevTracker is a modern and intuitive project management app designed specifically for developers. It helps streamline task organization, track deadlines, and monitor progress to maximize productivity and collaboration.

Developed with passion by [elijahrex2024](https://github.com/elijahrex2024).

---

## Features

- Create, edit, and organize tasks with ease
- Set deadlines and reminders to stay on track
- Visual progress charts and analytics
- Collaborative task assignment and status updates
- Responsive design for desktop and mobile

---

## Tech Stack

- React.js for a dynamic, responsive UI
- Node.js and Express for the backend API
- MongoDB for flexible data storage
- JWT Authentication for secure user sessions
- Chart.js for data visualization

---

## Installation

1. Clone the repository:

   ```
   git clone https://github.com/elijahrex2024/DevTracker.git
   ```

2. Navigate to the project directory:

   ```
   cd DevTracker
   ```

3. Install backend dependencies:

   ```
   cd backend
   npm install
   ```

4. Install frontend dependencies:

   ```
   cd ../frontend
   npm install
   ```

5. Set up your `.env` file in the backend folder with your MongoDB URI and JWT secret.

6. Run backend server:

   ```
   npm start
   ```

7. Run frontend development server:

   ```
   npm start
   ```

---

## Usage

Once running, open your browser to `http://localhost:3000` to access DevTracker. Create an account or log in to start managing your projects and tasks. Use the dashboard to view your progress and deadlines at a glance.
